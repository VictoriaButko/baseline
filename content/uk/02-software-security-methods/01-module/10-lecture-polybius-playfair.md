## Від моноалфавітних до поліграмних шифрів

До цього ми вивчали шифри, які обробляють **по одній літері**. Головна проблема таких шифрів — вразливість до частотного аналізу.

**Ідея поліграмних шифрів:** шифрувати **групи літер** (біграми, триграми), щоб "розмити" частотні характеристики. Окремих літер у латиниці 26, а біграм — 676: частоти біграм розподілені набагато рівніше, і для статистики потрібно в десятки разів більше тексту.

```
Моноалфавітний:    H → X,  E → Z,  L → Q,  L → Q,  O → M
                   "HELLO" → "XZQQM"

Біграмний:         HE → XP,  LL → QR,  O? → ...
                   Пари літер → пари літер
```

## Квадрат Полібія

### Історія

**Полібій** (200–118 рр. до н.е.) — грецький історик, запропонував систему передачі повідомлень за допомогою факелів.

**Йоганн Трисемус** (1462–1516) — бенедиктинський абат, першим описав побудову таблиці за ключовим словом. Його власний метод заміни — окремий шифр, ми розберемо його далі.

### Побудова квадрата

Квадрат 5×5 містить 25 літер (I та J об'єднуються):

```
    1   2   3   4   5
  ┌───┬───┬───┬───┬───┐
1 │ A │ B │ C │ D │ E │
  ├───┼───┼───┼───┼───┤
2 │ F │ G │ H │ I/J│ K │
  ├───┼───┼───┼───┼───┤
3 │ L │ M │ N │ O │ P │
  ├───┼───┼───┼───┼───┤
4 │ Q │ R │ S │ T │ U │
  ├───┼───┼───┼───┼───┤
5 │ V │ W │ X │ Y │ Z │
  └───┴───┴───┴───┴───┘
```

### Шифрування координатами

Кожна літера замінюється парою цифр (рядок, стовпець):

```
H → (2,3) → "23"
E → (1,5) → "15"
L → (3,1) → "31"
L → (3,1) → "31"
O → (3,4) → "34"

"HELLO" → "23 15 31 31 34"
```

### Квадрат з ключовим словом

```
Ключове слово: CRYPTO

    1   2   3   4   5
  ┌───┬───┬───┬───┬───┐
1 │ C │ R │ Y │ P │ T │  ← Ключ без повторів
  ├───┼───┼───┼───┼───┤
2 │ O │ A │ B │ D │ E │  ← Далі решта абетки за порядком,
  ├───┼───┼───┼───┼───┤     пропускаючи вже використані
3 │ F │ G │ H │ I/J│ K │     літери C, R, Y, P, T, O
  ├───┼───┼───┼───┼───┤
4 │ L │ M │ N │ Q │ S │
  ├───┼───┼───┼───┼───┤
5 │ U │ V │ W │ X │ Z │
  └───┴───┴───┴───┴───┘

Перевірка: у квадраті рівно 25 різних літер, J об'єднано з I.

"HELLO" за цим квадратом → H(33) E(25) L(41) L(41) O(21) → "33 25 41 41 21"
```

### Реалізація

```cpp
#include <iostream>
#include <string>
#include <map>
#include <cctype>

// Квадрат Полібія: кожна літера подається парою «рядок-стовпець»
class PolybiusSquare {
public:
    explicit PolybiusSquare(const std::string& keyword = "") {
        bool used[26] = { false };

        for (char c : keyword) {                       // спершу літери ключа
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';                   // J і I займають одну клітинку
            if (up >= 'A' && up <= 'Z' && !used[up - 'A']) {
                used[up - 'A'] = true;
                alphabet_ += up;
            }
        }
        for (char c : std::string("ABCDEFGHIKLMNOPQRSTUVWXYZ")) {   // далі решта
            if (!used[c - 'A']) {
                used[c - 'A'] = true;
                alphabet_ += c;
            }
        }

        for (size_t i = 0; i < alphabet_.size(); ++i) {
            std::string code = std::to_string(i / 5 + 1) + std::to_string(i % 5 + 1);
            encode_[alphabet_[i]] = code;
            decode_[code] = alphabet_[i];
        }
    }

    std::string encrypt(const std::string& text) const {
        std::string result;
        for (char c : text) {
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';
            auto it = encode_.find(up);
            if (it != encode_.end()) result += it->second;
        }
        return result;
    }

    std::string decrypt(const std::string& digits) const {
        std::string result;
        for (size_t i = 0; i + 1 < digits.size(); i += 2) {
            auto it = decode_.find(digits.substr(i, 2));
            if (it != decode_.end()) result += it->second;
        }
        return result;
    }

    const std::string& grid() const { return alphabet_; }

private:
    std::string alphabet_;
    std::map<char, std::string> encode_;
    std::map<std::string, char> decode_;
};

int main() {
    PolybiusSquare square("CRYPTO");

    std::string encrypted = square.encrypt("ATTACK");
    std::cout << "Квадрат:      " << square.grid() << "\n";
    std::cout << "Зашифровано:  " << encrypted << "\n";
    std::cout << "Розшифровано: " << square.decrypt(encrypted) << "\n";
    return 0;
}
```

## Таблиця Трисемуса

Квадрат Полібія — не єдиний спосіб використати таблицю 5×5. Трисемус запропонував інший:
літеру замінюють **не координатами, а сусідньою літерою в тому самому стовпці**.

### Правило

Таблиця будується так само, як квадрат Полібія з ключовим словом. Щоб зашифрувати літеру,
беруть ту, що стоїть **безпосередньо під нею**; з останнього рядка переходять у перший (цикл).
Щоб розшифрувати — беруть літеру **зверху**.

```
Ключове слово: CRYPTO

    1   2   3   4   5
  ┌───┬───┬───┬───┬───┐
1 │ C │ R │ Y │ P │ T │
  ├───┼───┼───┼───┼───┤
2 │ O │ A │ B │ D │ E │
  ├───┼───┼───┼───┼───┤
3 │ F │ G │ H │ I/J│ K │
  ├───┼───┼───┼───┼───┤
4 │ L │ M │ N │ Q │ S │
  ├───┼───┼───┼───┼───┤
5 │ U │ V │ W │ X │ Z │
  └───┴───┴───┴───┴───┘

H (рядок 3, стовпець 3) → літера під нею, N
E (рядок 2, стовпець 5) → K
L (рядок 4, стовпець 1) → U
L                       → U
O (рядок 2, стовпець 1) → F

"HELLO" → "NKUUF"
```

Перехід через нижній край:

```
Z (рядок 5, стовпець 5) → рядок 1 того ж стовпця → T
E (рядок 2, стовпець 5) → K
U (рядок 5, стовпець 1) → рядок 1 → C
S (рядок 4, стовпець 5) → Z

"ZEUS" → "TKCZ"
```

### Чим Трисемус відрізняється від Полібія

| | Квадрат Полібія | Таблиця Трисемуса |
|---|---|---|
| Результат заміни | пара цифр | одна літера |
| Довжина шифротексту | удвічі більша за текст | така сама, як текст |
| Тип шифру | моноалфавітна заміна з фракціонуванням | моноалфавітна заміна |
| Стійкість | низька, частотний аналіз працює | низька, частотний аналіз працює |

Обидва методи однаково вразливі до частотного аналізу — це й стало приводом перейти до
поліграмних шифрів, які обробляють не одну літеру, а пару.

### Реалізація

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cctype>

// Таблиця Трисемуса: літеру замінює сусідка знизу в тому самому стовпці
class TrithemiusTable {
public:
    explicit TrithemiusTable(const std::string& keyword) {
        bool used[26] = { false };
        std::string chars;

        for (char c : keyword) {
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';
            if (up >= 'A' && up <= 'Z' && !used[up - 'A']) {
                used[up - 'A'] = true;
                chars += up;
            }
        }
        for (char c : std::string("ABCDEFGHIKLMNOPQRSTUVWXYZ")) {
            if (!used[c - 'A']) { used[c - 'A'] = true; chars += c; }
        }

        table_.resize(5);
        for (int row = 0; row < 5; ++row) table_[row] = chars.substr(row * 5, 5);
    }

    std::string encrypt(const std::string& text) const { return shift(text, +1); }
    std::string decrypt(const std::string& text) const { return shift(text, -1); }

private:
    // step = +1 — беремо літеру знизу, -1 — зверху; рядки замкнені в цикл
    std::string shift(const std::string& text, int step) const {
        std::string result;
        for (char c : text) {
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';
            if (up < 'A' || up > 'Z') continue;

            for (int row = 0; row < 5; ++row) {
                size_t col = table_[row].find(up);
                if (col != std::string::npos) {
                    result += table_[(row + step + 5) % 5][col];
                    break;
                }
            }
        }
        return result;
    }

    std::vector<std::string> table_;
};

int main() {
    TrithemiusTable table("CRYPTO");

    std::string encrypted = table.encrypt("HELLO");
    std::cout << "Зашифровано:  " << encrypted << "\n";   // NKUUF
    std::cout << "Розшифровано: " << table.decrypt(encrypted) << "\n";
    return 0;
}
```

## Шифр Плейфера

### Історія

Винайдений **Чарльзом Уітстоном** у 1854 році, але названий на честь його друга **Лорда Плейфера**, який популяризував шифр.

Використовувався британською армією в Другій Бурській війні та Першій світовій.

### Принцип роботи

1. Будуємо матрицю 5×5 з ключовим словом
2. Розбиваємо текст на **біграми** (пари літер)
3. Шифруємо кожну біграму за правилами

### Побудова матриці

```
Ключове слово: PLAYFAIR

┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │
├───┼───┼───┼───┼───┤
│ I │ R │ B │ C │ D │
├───┼───┼───┼───┼───┤
│ E │ G │ H │ K │ M │
├───┼───┼───┼───┼───┤
│ N │ O │ Q │ S │ T │
├───┼───┼───┼───┼───┤
│ U │ V │ W │ X │ Z │
└───┴───┴───┴───┴───┘
```

### Підготовка тексту

1. Замінити J на I
2. Розбити на пари
3. Якщо в парі однакові літери — вставити X між ними
4. Якщо непарна кількість — додати X в кінці

```
"HELLO" → "HE" "LX" "LO"  (LL → LX + LO)
"TREE"  → "TR" "EX" "EX"  (у парі EE вставляємо X → "EX"; решта — "E" + X у кінці)
```

### Правила шифрування біграм

**Правило 1: Один рядок**

Беремо літери праворуч (з циклом).

```
┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │  ← PL → LA
└───┴───┴───┴───┴───┘

P L → L A
Y F → F P (цикл!)
```

**Правило 2: Один стовпець**

Беремо літери знизу (з циклом).

```
│ P │
│ I │  ← PI → IE
│ E │
│ N │
│ U │

P I → I E
N U → U P (цикл!)
```

**Правило 3: Прямокутник**

Кожна літера замінюється тією, що стоїть у **її власному рядку**, але в стовпці другої літери.

```
        1   2   3   4   5
      ┌───┬───┬───┬───┬───┐
    1 │ P │ L │ A │ Y │ F │
      ├───┼───┼───┼───┼───┤
    2 │ I │ R │ B │ C │[D]│  D — рядок 2, стовпець 5
      ├───┼───┼───┼───┼───┤
    3 │ E │ G │[H]│ K │[M]│  H — рядок 3, стовпець 3
      └───┴───┴───┴───┴───┘

H (рядок 3) бере стовпець D (5) → M
D (рядок 2) бере стовпець H (3) → B

H D → M B
```

### Приклад шифрування

```
Повідомлення: HELLO WORLD
Ключ: PLAYFAIR

Матриця:
┌───┬───┬───┬───┬───┐
│ P │ L │ A │ Y │ F │
├───┼───┼───┼───┼───┤
│ I │ R │ B │ C │ D │
├───┼───┼───┼───┼───┤
│ E │ G │ H │ K │ M │
├───┼───┼───┼───┼───┤
│ N │ O │ Q │ S │ T │
├───┼───┼───┼───┼───┤
│ U │ V │ W │ X │ Z │
└───┴───┴───┴───┴───┘

Розбиваємо: HE LX LO WO RL DX

HE → (один рядок 3)      → KG
LX → (прямокутник)       → YV
LO → (один стовпець 2)   → RV
WO → (прямокутник)       → VQ
RL → (один стовпець 2)   → GR
DX → (прямокутник)       → CZ

Шифротекст: KG YV RV VQ GR CZ
```

Розберімо дві біграми докладно:

```
LX: L — рядок 1, стовпець 2;  X — рядок 5, стовпець 4
    різні рядки й стовпці → прямокутник
    L бере стовпець X (4) у своєму рядку 1 → Y
    X бере стовпець L (2) у своєму рядку 5 → V
    LX → YV

RL: R — рядок 2, стовпець 2;  L — рядок 1, стовпець 2
    однаковий стовпець → зсув униз із циклом
    R (рядок 2) → рядок 3 → G
    L (рядок 1) → рядок 2 → R
    RL → GR
```

### Реалізація мовою C++

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cctype>

class PlayfairCipher {
public:
    explicit PlayfairCipher(const std::string& keyword) {
        buildMatrix(keyword);
    }

    std::string encrypt(const std::string& text) const {
        return process(prepare(text), +1);
    }

    std::string decrypt(const std::string& text) const {
        return process(text, -1);
    }

    void print() const {
        for (const std::string& row : matrix_) {
            for (char c : row) std::cout << c << ' ';
            std::cout << "\n";
        }
    }

private:
    void buildMatrix(const std::string& keyword) {
        bool used[26] = { false };
        std::string chars;

        for (char c : keyword) {
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';
            if (up >= 'A' && up <= 'Z' && !used[up - 'A']) {
                used[up - 'A'] = true;
                chars += up;
            }
        }
        for (char c : std::string("ABCDEFGHIKLMNOPQRSTUVWXYZ")) {
            if (!used[c - 'A']) { used[c - 'A'] = true; chars += c; }
        }

        matrix_.resize(5);
        for (int row = 0; row < 5; ++row) matrix_[row] = chars.substr(row * 5, 5);
    }

    // Текст розбивається на біграми; однакові літери розділяються літерою X
    std::string prepare(const std::string& text) const {
        std::string clean;
        for (char c : text) {
            if (std::isalpha(static_cast<unsigned char>(c))) {
                char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
                clean += (up == 'J') ? 'I' : up;
            }
        }

        std::string result;
        for (size_t i = 0; i < clean.size(); ++i) {
            result += clean[i];
            if (result.size() % 2 == 1 && i + 1 < clean.size() && clean[i] == clean[i + 1]) {
                result += 'X';
            }
        }
        if (result.size() % 2 == 1) result += 'X';
        return result;
    }

    void findPosition(char c, int& row, int& col) const {
        for (row = 0; row < 5; ++row) {
            for (col = 0; col < 5; ++col) {
                if (matrix_[row][col] == c) return;
            }
        }
    }

    // shift = +1 для зашифрування, -1 для розшифрування
    std::string process(const std::string& text, int shift) const {
        std::string result;

        for (size_t i = 0; i + 1 < text.size(); i += 2) {
            int r1, c1, r2, c2;
            findPosition(text[i], r1, c1);
            findPosition(text[i + 1], r2, c2);

            if (r1 == r2) {                       // один рядок
                result += matrix_[r1][(c1 + shift + 5) % 5];
                result += matrix_[r2][(c2 + shift + 5) % 5];
            } else if (c1 == c2) {                // один стовпець
                result += matrix_[(r1 + shift + 5) % 5][c1];
                result += matrix_[(r2 + shift + 5) % 5][c2];
            } else {                              // прямокутник
                result += matrix_[r1][c2];
                result += matrix_[r2][c1];
            }
        }
        return result;
    }

    std::vector<std::string> matrix_;
};

int main() {
    PlayfairCipher cipher("MONARCHY");
    cipher.print();

    std::string encrypted = cipher.encrypt("HELLO WORLD");
    std::cout << "\nЗашифровано:  " << encrypted << "\n";
    std::cout << "Розшифровано: " << cipher.decrypt(encrypted) << "\n";
    return 0;
}
```

## Подвійний квадрат Уітстона

### Ідея

Використовуємо **дві** матриці 5×5, розташовані **одна над одною**. Таке розташування —
не декорація: воно робить правило шифрування наочним. Дві літери біграми задають два
протилежні кути прямокутника, а шифротекст беруть з двох інших кутів.

```
Матриця 1 — ВЕРХНЯ (ключ: EXAMPLE)

┌───┬───┬───┬───┬───┐
│ E │ X │ A │ M │ P │
├───┼───┼───┼───┼───┤
│ L │ B │ C │ D │ F │
├───┼───┼───┼───┼───┤
│ G │ H │ I │ K │ N │
├───┼───┼───┼───┼───┤
│ O │ Q │ R │ S │ T │
├───┼───┼───┼───┼───┤
│ U │ V │ W │ Y │ Z │
└───┴───┴───┴───┴───┘

Матриця 2 — НИЖНЯ (ключ: KEYWORD)

┌───┬───┬───┬───┬───┐
│ K │ E │ Y │ W │ O │
├───┼───┼───┼───┼───┤
│ R │ D │ A │ B │ C │
├───┼───┼───┼───┼───┤
│ F │ G │ H │ I │ L │
├───┼───┼───┼───┼───┤
│ M │ N │ P │ Q │ S │
├───┼───┼───┼───┼───┤
│ T │ U │ V │ X │ Z │
└───┴───┴───┴───┴───┘
```

> На дошці чи в зошиті малюйте квадрати саме один під одним. У розкладці «поруч»
> правило «протилежні кути» перестає бути геометрично правдивим і збиває з пантелику.

### Правила шифрування

1. Перша літера біграми шукається у **верхньому** квадраті, друга — у **нижньому**
2. Дві літери — протилежні кути прямокутника, що лежить на обох квадратах
3. Перша літера шифротексту — у **верхньому** квадраті: рядок першої літери, стовпець другої
4. Друга літера шифротексту — у **нижньому** квадраті: рядок другої літери, стовпець першої

```
Біграма: AT

A у верхньому квадраті: рядок 0, стовпець 2
T у нижньому квадраті:  рядок 4, стовпець 0

      0   1   2   3   4
    ┌───┬───┬───┬───┬───┐
  0 │[E]│ X │[A]│ M │ P │   ВЕРХНЯ
    ├───┼───┼───┼───┼───┤
  1 │ L │ B │ C │ D │ F │
    ├───┼───┼───┼───┼───┤
  2 │ G │ H │ I │ K │ N │
    ├───┼───┼───┼───┼───┤
  3 │ O │ Q │ R │ S │ T │
    ├───┼───┼───┼───┼───┤
  4 │ U │ V │ W │ Y │ Z │
    └───┴───┴───┴───┴───┘

    ┌───┬───┬───┬───┬───┐
  0 │ K │ E │ Y │ W │ O │   НИЖНЯ
    ├───┼───┼───┼───┼───┤
  1 │ R │ D │ A │ B │ C │
    ├───┼───┼───┼───┼───┤
  2 │ F │ G │ H │ I │ L │
    ├───┼───┼───┼───┼───┤
  3 │ M │ N │ P │ Q │ S │
    ├───┼───┼───┼───┼───┤
  4 │[T]│ U │[V]│ X │ Z │
    └───┴───┴───┴───┴───┘

Прямокутник: A (верх, 0-2) — T (низ, 4-0) — і два інші кути E (верх, 0-0) та V (низ, 4-2)

У верхній матриці беремо рядок A (0) і стовпець T (0) → E
У нижній матриці беремо рядок T (4) і стовпець A (2) → V

AT → EV
```

**Вироджений випадок.** Якщо обидві літери стоять в однаковому стовпці своїх квадратів,
прямокутник вироджується у вертикальну лінію і біграма лишається без змін: `HE → HE`,
`SI → SI`. Це відома слабкість подвійного квадрата — приблизно кожна п'ята біграма
(імовірність 1/5, що стовпці збіжуться) проходить крізь шифр незміненою, і криптоаналітик
одразу бачить у шифротексті шматки відкритого тексту. Тому на практиці подвійний квадрат
зазвичай доповнювали іншими перетвореннями.

### Переваги подвійного квадрата

1. **Більший простір ключів**: два незалежних ключових слова
2. **Стійкіший до частотного аналізу**: біграми розподіляються рівномірніше
3. **Немає потреби розділяти однакові літери**: пара LL обробляється звичайним чином,
   вставляти X не доводиться

### Реалізація

```cpp
#include <iostream>
#include <string>
#include <vector>

// Подвійний квадрат Уітстона: перша літера біграми шукається у верхньому
// квадраті, друга — у нижньому, результат беруть із протилежних кутів
class TwoSquareCipher {
public:
    TwoSquareCipher(const std::string& keyword1, const std::string& keyword2)
        : top_(buildMatrix(keyword1)), bottom_(buildMatrix(keyword2)) {}

    std::string process(const std::string& text) const {
        std::string result;

        for (size_t i = 0; i + 1 < text.size(); i += 2) {
            int r1, c1, r2, c2;
            findPosition(top_, text[i], r1, c1);
            findPosition(bottom_, text[i + 1], r2, c2);

            result += top_[r1][c2];       // рядок першої літери, стовпець другої
            result += bottom_[r2][c1];    // рядок другої літери, стовпець першої
        }
        return result;
    }

    // Перетворення симетричне: повторне застосування повертає вихідний текст
    std::string encrypt(const std::string& text) const { return process(text); }
    std::string decrypt(const std::string& text) const { return process(text); }

private:
    static std::vector<std::string> buildMatrix(const std::string& keyword) {
        bool used[26] = { false };
        std::string chars;

        for (char c : keyword) {
            char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
            if (up == 'J') up = 'I';
            if (up >= 'A' && up <= 'Z' && !used[up - 'A']) {
                used[up - 'A'] = true;
                chars += up;
            }
        }
        for (char c : std::string("ABCDEFGHIKLMNOPQRSTUVWXYZ")) {
            if (!used[c - 'A']) { used[c - 'A'] = true; chars += c; }
        }

        std::vector<std::string> matrix(5);
        for (int row = 0; row < 5; ++row) matrix[row] = chars.substr(row * 5, 5);
        return matrix;
    }

    static void findPosition(const std::vector<std::string>& matrix, char c, int& row, int& col) {
        for (row = 0; row < 5; ++row) {
            for (col = 0; col < 5; ++col) {
                if (matrix[row][col] == c) return;
            }
        }
    }

    std::vector<std::string> top_, bottom_;
};

int main() {
    TwoSquareCipher cipher("EXAMPLE", "KEYWORD");

    std::string encrypted = cipher.encrypt("HELLOWORLD");
    std::cout << "Зашифровано:  " << encrypted << "\n";
    std::cout << "Розшифровано: " << cipher.decrypt(encrypted) << "\n";
    return 0;
}
```

## Криптоаналіз шифру Плейфера

Плейфер — це по суті блочний шифр із блоком у дві літери: він замінює кожну біграму іншою за фіксованою таблицею на 25 × 24 = 600 можливих біграм. Така таблиця надто мала, щоб сховати статистику мови, і шифр видає себе кількома властивостями:

1. **Аналіз біграм**: частоти біграм шифротексту відображають частоти біграм мови (TH, HE, IN, ER…).
2. **Реверс**: якщо AB → XY, то BA → YX — прямокутник симетричний.
3. **Жодна літера не шифрується сама в себе**, і в шифротексті ніколи немає біграм із двох однакових літер.
4. **Відомий фрагмент тексту** («ймовірне слово») відновлює частину матриці, а решта добудовується за правилом ключового слова.

Перший опублікований метод зламу Плейфера описав американський офіцер Джозеф Моборн 1914 року, і в Першу світову шифр вважали придатним лише для тактичних повідомлень, що втрачають цінність за кілька годин. Сьогодні програма з hill climbing відновлює матрицю за кількома сотнями літер шифротексту.

// Стисле створення матриці Плейфера
std::vector<std::string> createPlayfairMatrix(const std::string& keyword) {
    std::string chars;
    for (char c : keyword + "ABCDEFGHIKLMNOPQRSTUVWXYZ") {
        char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
        if (up == 'J') up = 'I';
        if (up >= 'A' && up <= 'Z' && chars.find(up) == std::string::npos) chars += up;
    }

    std::vector<std::string> matrix(5);
    for (int row = 0; row < 5; ++row) matrix[row] = chars.substr(row * 5, 5);
    return matrix;
}

// Пошук позиції літери в матриці
bool findPosition(const std::vector<std::string>& matrix, char c, int& row, int& col) {
    for (row = 0; row < 5; ++row) {
        size_t pos = matrix[row].find(c);
        if (pos != std::string::npos) {
            col = static_cast<int>(pos);
            return true;
        }
    }
    return false;
}

std::vector<std::string> buildPlayfairTable(const std::string& keyword) {
    bool used[26] = { false };
    std::string chars;

    for (char c : keyword) {
        char up = static_cast<char>(std::toupper(static_cast<unsigned char>(c)));
        if (up == 'J') up = 'I';
        if (up >= 'A' && up <= 'Z' && !used[up - 'A']) {
            used[up - 'A'] = true;
            chars += up;
        }
    }
    for (char c : std::string("ABCDEFGHIKLMNOPQRSTUVWXYZ")) {   // без J
        if (!used[c - 'A']) { used[c - 'A'] = true; chars += c; }
    }

    std::vector<std::string> table(5);
    for (int row = 0; row < 5; ++row) table[row] = chars.substr(row * 5, 5);
    return table;
}
