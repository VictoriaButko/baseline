## Теоретичні відомості

### 1 Основні поняття

Криптографія — це галузь знань, яка вивчає методи перетворення інформації з метою приховування її змісту від сторонніх осіб. Разом із криптоаналізом, що досліджує методи розкриття такого перетворення без знання ключа, вона утворює криптологію.

Вихідне повідомлення, зміст якого потрібно приховати, називають відкритим текстом; результат його перетворення — шифротекстом (криптограмою). Перетворення відкритого тексту на шифротекст називають зашифруванням, зворотне перетворення — розшифруванням. Обидві операції виконуються за певним алгоритмом, який залежить від параметра, що називається ключем.

Сукупність «алгоритм + ключ» утворює шифр. Відповідно до правила Керкгоффса, стійкість шифру має ґрунтуватися виключно на таємності ключа: вважається, що алгоритм відомий супротивнику. Криптостійкістю називають здатність шифру протистояти спробам розкриття.

За характером перетворення класичні шифри поділяють на:

- шифри заміни (підстановки) — символи відкритого тексту замінюються іншими символами;
- шифри перестановки — символи залишаються тими самими, змінюється лише порядок їх розташування.

Шифри заміни, у свою чергу, поділяють на моноалфавітні (кожному символу відповідає один і той самий замінник упродовж усього повідомлення) і поліалфавітні (замінник залежить від позиції символу).

### 2 Шифр простої заміни

Нехай задано алфавіт A = {a₀, a₁, …, aₙ₋₁} потужністю N. Шифр простої (одноалфавітної) заміни визначається взаємно однозначним відображенням π: A → A. Зашифрування полягає в заміні кожного символу aᵢ на символ π(aᵢ), розшифрування — у застосуванні оберненої підстановки π⁻¹.

Ключем такого шифру є сама підстановка, тому кількість можливих ключів дорівнює N!. Для української абетки з 33 літер це приблизно 8,68·10³⁶ варіантів, що робить повний перебір ключів практично неможливим. Попри це, шифр простої заміни не є стійким: він не змінює статистичних властивостей мови, а тому легко розкривається частотним аналізом.

### 3 Шифр Цезаря

Шифр Цезаря — окремий випадок шифру простої заміни, у якому підстановка задається циклічним зсувом алфавіту на фіксовану кількість позицій k. Якщо позначити через Pᵢ порядковий номер i-го символу відкритого тексту в алфавіті, а через Cᵢ — номер відповідного символу шифротексту, то:

Cᵢ = (Pᵢ + k) mod N — зашифрування;

Pᵢ = (Cᵢ − k + N) mod N — розшифрування.

Величина k і є ключем шифру. Значення k = 0 залишає текст без змін, тому кількість практично корисних ключів дорівнює N − 1, тобто 32 для української абетки і 25 для англійської. Такий розмір ключового простору робить шифр Цезаря беззахисним перед атакою повним перебором (brute force): достатньо перевірити всі варіанти та обрати той, що дає осмислений текст.

**Приклад.** Українська абетка з 33 літер, ключ k = 3:

«захист» → «їгшйфх»

Літера «з» має номер 9; 9 + 3 = 12, а це літера «ї». Аналогічно «а» (0) → «г» (3), «х» (25) → «ш» (28) і так далі. Символи, яких немає в алфавіті (пробіли, розділові знаки, цифри), під час зашифрування зазвичай залишають без змін.

### 4 Частотні характеристики текстових повідомлень

Відносною частотою символу a в тексті довжиною n символів називають величину f(a) = n(a) / n, де n(a) — кількість входжень цього символу. Для природної мови відносні частоти літер є доволі сталими й мало залежать від конкретного тексту, якщо його обсяг достатній (щонайменше 300–500 літер). Наведені нижче усереднені значення для української мови є наближеними: вони залежать від стилю й тематики корпусу, за яким обчислювалися.

Ключова властивість моноалфавітної заміни полягає в тому, що вона не змінює набору частот, а лише переставляє їх між літерами. Для шифру Цезаря ця перестановка є циклічним зсувом гістограми частот на k позицій. Тому, знаючи еталонний розподіл, достатньо порівняти його з частотами шифротексту і знайти найкращий зсув.

### 5 Критерій χ² та визначення ключа

Зіставлення лише найчастішої літери (наприклад, «о» в українській мові) із найчастішою літерою шифротексту дає помилку на коротких текстах, де випадкові відхилення значні. Тому надійніше порівнювати весь розподіл. Для кожного припущеного ключа k текст розшифровують і обчислюють міру розходження з еталонним розподілом:

χ²(k) = Σ (nᵢ − eᵢ)² / eᵢ , де eᵢ = pᵢ · n

Тут nᵢ — фактична кількість входжень i-ї літери в розшифрованому тексті, pᵢ — її еталонна частка, n — загальна кількість літер. Шуканим ключем вважають те значення k, для якого χ²(k) є найменшим. На практиці достатньо перебрати N − 1 варіант і обрати кращий.

### 6 Порядок написання С++ програм

У лабораторних роботах з предмета програми виконуються з використанням мови С++. Кожна програма має містити:

- підключення необхідних бібліотек;
- коректну роботу з українським текстом: файли — у кодуванні UTF-8, у пам'яті — рядки `wstring` (у Windows `wchar_t` зберігає символ у UTF-16);
- меню користувача для вибору дій;
- окремі функції для зашифрування, розшифрування, аналізу частот тощо;
- читання вхідних даних з файлу та запис результатів у файл.

## Приклад виконання

```cpp
// codecvt_utf8 оголошено застарілим у C++17; у Visual Studio з увімкненими
// перевірками SDL це попередження C4996 стає помилкою, тому вимикаємо його
#define _SILENCE_CXX17_CODECVT_HEADER_DEPRECATION_WARNING

#include <iostream>
#include <fstream>
#include <string>
#include <vector>
#include <iomanip>
#include <cmath>
#include <locale>
#include <codecvt>

#ifdef _WIN32
#include <io.h>
#include <fcntl.h>
#endif

using namespace std;

const wstring ALPHA_LO = L"абвгґдеєжзиіїйклмнопрстуфхцчшщьюя";
const wstring ALPHA_UP = L"АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ";
const int N = 33;

// Еталонні частоти літер української мови, %
const double REF[N] = {
    7.55, 1.78, 5.45, 1.47, 0.01, 3.46, 4.82, 0.52, 1.05, 2.41,
    6.39, 5.97, 0.63, 1.26, 3.67, 3.56, 3.25, 6.39, 9.88, 3.04,
    4.61, 4.40, 4.61, 3.56, 0.31, 1.26, 1.05, 1.36, 0.73, 0.42,
    1.78, 0.94, 2.41
};

// Пошук індексу літери в алфавіті
int indexOf(wchar_t c, bool& upper) {
    size_t p = ALPHA_LO.find(c);
    if (p != wstring::npos) { upper = false; return (int)p; }
    p = ALPHA_UP.find(c);
    if (p != wstring::npos) { upper = true; return (int)p; }
    return -1;
}

// Читання тексту з файлу
wstring readFile(const string& name) {
    wifstream in(name);
    if (!in) {
        wcout << L"Помилка: файл не знайдено!\n";
        return L"";
    }
    in.imbue(locale(in.getloc(), new codecvt_utf8<wchar_t>));
    wstring text((istreambuf_iterator<wchar_t>(in)),
                  istreambuf_iterator<wchar_t>());
    return text;
}

// Запис тексту у файл
bool writeFile(const string& name, const wstring& text) {
    wofstream out(name);
    if (!out) return false;
    out.imbue(locale(out.getloc(), new codecvt_utf8<wchar_t>));
    out << text;
    return true;
}

// Зашифрування шифром Цезаря
wstring encrypt(const wstring& text, int k) {
    k = ((k % N) + N) % N;
    wstring res = text;
    for (size_t i = 0; i < res.size(); i++) {
        bool up = false;
        int p = indexOf(res[i], up);
        if (p >= 0)
            res[i] = up ? ALPHA_UP[(p + k) % N] : ALPHA_LO[(p + k) % N];
    }
    return res;
}

// Розшифрування шифром Цезаря
wstring decrypt(const wstring& text, int k) {
    return encrypt(text, N - ((k % N) + N) % N);
}

// Підрахунок частот літер
vector<double> frequencies(const wstring& text, long& total) {
    vector<double> f(N, 0.0);
    total = 0;
    for (size_t i = 0; i < text.size(); i++) {
        bool up = false;
        int p = indexOf(text[i], up);
        if (p >= 0) { f[p] += 1.0; total++; }
    }
    if (total > 0)
        for (int i = 0; i < N; i++)
            f[i] = f[i] * 100.0 / total;
    return f;
}

// Друк таблиці частот із гістограмою
void printFrequencies(const vector<double>& f, long total) {
    wcout << L"+-------+----------+----------+----------------------+\n";
    wcout << L"| Літера| Частота  | Еталон   | Гістограма           |\n";
    wcout << L"+-------+----------+----------+----------------------+\n";
    for (int i = 0; i < N; i++) {
        wcout << L"| " << ALPHA_LO[i] << L"     | "
              << fixed << setprecision(2) << setw(6) << f[i] << L" % | "
              << setw(6) << REF[i] << L" % | ";
        int bars = (int)(f[i] * 2 + 0.5);
        wstring bar(bars > 20 ? 20 : bars, L'#');
        wcout << left << setw(20) << bar << right << L" |\n";
    }
    wcout << L"+-------+----------+----------+----------------------+\n";
    wcout << L"Усього літер у тексті: " << total << L"\n";
}

// Злам повним перебором ключів
void bruteForce(const wstring& text) {
    wcout << L"Перебір усіх " << N - 1 << L" можливих ключів:\n";
    for (int k = 1; k < N; k++) {
        wstring t = decrypt(text, k);
        if (t.size() > 48) t = t.substr(0, 48) + L"...";
        wcout << L"k = " << setw(2) << k << L" : " << t << L"\n";
    }
}

// Автоматичне визначення ключа за критерієм хі-квадрат
int findKey(const wstring& text, double& bestChi) {
    int bestK = 0;
    bestChi = 1e18;
    for (int k = 0; k < N; k++) {
        long total = 0;
        vector<double> f = frequencies(decrypt(text, k), total);
        if (total == 0) return 0;
        double chi = 0.0;
        for (int i = 0; i < N; i++) {
            double obs = f[i] * total / 100.0;
            double exp = REF[i] * total / 100.0;
            if (exp < 0.5) exp = 0.5;
            chi += (obs - exp) * (obs - exp) / exp;
        }
        if (chi < bestChi) { bestChi = chi; bestK = k; }
    }
    return bestK;
}

// Меню користувача
void menu() {
    wcout << L"\n=============== МЕНЮ ===============\n"
          << L" 1 - завантажити текст із файлу\n"
          << L" 2 - показати поточний текст\n"
          << L" 3 - зашифрувати шифром Цезаря\n"
          << L" 4 - розшифрувати за відомим ключем\n"
          << L" 5 - частотний аналіз тексту\n"
          << L" 6 - злам повним перебором ключів\n"
          << L" 7 - автоматичне визначення ключа\n"
          << L" 8 - зберегти текст у файл\n"
          << L" 0 - вихід\n"
          << L"====================================\n"
          << L"Ваш вибір: ";
}

int main() {
#ifdef _WIN32
    _setmode(_fileno(stdout), _O_U16TEXT);
    _setmode(_fileno(stdin), _O_U16TEXT);
#else
    locale::global(locale(""));
    wcout.imbue(locale());
#endif

    wstring text = L"";
    int item = -1, k = 0;
    long total = 0;

    while (item != 0) {
        menu();
        if (!(wcin >> item)) {
            // Кінець введення (Ctrl+D, Ctrl+Z або перенаправлений файл) —
            // виходимо, інакше цикл крутився б нескінченно
            if (wcin.eof()) break;
            wcin.clear();
            wcin.ignore(1000, L'\n');
            item = -1;
        }
        switch (item) {
            case 1:
                text = readFile("plain.txt");
                if (!text.empty())
                    wcout << L"Текст завантажено, символів: "
                          << text.size() << L"\n";
                break;
            case 2:
                wcout << L"--- Поточний текст ---\n" << text << L"\n";
                break;
            case 3:
                wcout << L"Введіть ключ (1.." << N - 1 << L"): ";
                wcin >> k;
                if (k < 1 || k > N - 1) {
                    wcout << L"Некоректний ключ!\n";
                    break;
                }
                text = encrypt(text, k);
                wcout << L"Текст зашифровано.\n";
                break;
            case 4:
                wcout << L"Введіть ключ (1.." << N - 1 << L"): ";
                wcin >> k;
                if (k < 1 || k > N - 1) {
                    wcout << L"Некоректний ключ!\n";
                    break;
                }
                text = decrypt(text, k);
                wcout << L"Текст розшифровано.\n";
                break;
            case 5: {
                vector<double> f = frequencies(text, total);
                if (total == 0) {
                    wcout << L"Текст порожній!\n";
                    break;
                }
                printFrequencies(f, total);
                break;
            }
            case 6:
                bruteForce(text);
                break;
            case 7: {
                double chi = 0;
                int key = findKey(text, chi);
                wcout << L"Знайдений ключ: k = " << key
                      << L" (хі-квадрат = " << fixed << setprecision(1)
                      << chi << L")\n";
                break;
            }
            case 8:
                if (writeFile("result.txt", text))
                    wcout << L"Збережено у result.txt\n";
                else
                    wcout << L"Помилка запису!\n";
                break;
            case 0:
                wcout << L"Роботу завершено.\n";
                break;
            default:
                wcout << L"Такого пункту меню немає!\n";
        }
    }
    return 0;
}
```

```
| т     |   4.94 % |   4.61 % | ##########           |
+-------+----------+----------+----------------------+
Усього літер у тексті: 809

Ваш вибір: 3
Введіть ключ (1..32): 7
Текст зашифровано.

Ваш вибір: 7
Знайдений ключ: k = 7 (хі-квадрат = 42.4)
```

Зверніть увагу: у цьому тексті найчастіша літера — «а» (9,89 %), а не «о»
(9,02 %), як в еталоні. Сусіди в рейтингу помінялися місцями, і гіпотеза
«найчастіша літера шифротексту — це о» дала б хибний ключ 22. Хі-квадрат
порівнює всі 33 частоти одночасно, тому такої помилки не робить: після зсуву на
правильний ключ гістограма шифротексту накладається на еталонну всією формою.
Програма перебирає всі ключі й лишає той, для якого розбіжність найменша.

**Запуск поза Windows.** Програма виводить українські літери через `wcout`,
тому на Linux і macOS її треба запускати з локаллю UTF-8, інакше потік
переходить у стан помилки на першій же кирилиці й вивід обривається:

```bash
LC_ALL=en_US.UTF-8 ./caesar
```

Порівняння таблиць частот: набір значень частот у відкритому й шифрованому текстах збігається (9,89 %; 9,02 %; 7,05 % тощо), змінилися лише літери, яким ці значення належать. Літера «а» (9,89 %) перейшла в «є», «о» (9,02 %) — у «х», «и» (7,05 %) — у «н». Будь-яка з цих пар дає той самий ключ: номер «х» дорівнює 25, номер «о» — 18, різниця 25 − 18 = 7.

## Порядок виконання роботи

1. Ознайомитися з теоретичними відомостями та отримати в викладача номер індивідуального варіанта.

2. Описати детальну постановку задачі згідно з індивідуальним варіантом із зазначенням вхідних і вихідних даних, використаного алфавіту, його потужності N та діапазону допустимих значень ключа.

3. Підготувати текстовий файл із відкритим повідомленням відповідною мовою обсягом не менше ніж 800 літер. Файл зберегти в кодуванні UTF-8.

4. Скласти програму мовою С++ таким чином, щоб вона відповідала таким критеріям: усі дії, передбачені умовою задачі, реалізовані окремими функціями; передбачене меню користувача; обов'язково реалізовані зашифрування, розшифрування за відомим ключем, обчислення частотних характеристик, злам повним перебором ключів і автоматичне визначення ключа за частотами; читання вихідного тексту з файлу та збереження результатів у файл; таблиця частот виводиться з наочною гістограмою; тестування набором вхідних значень — правильних і завідомо неправильних.

5. Виконати експеримент: зашифрувати підготовлений текст, побудувати таблиці частот відкритого й шифрованого текстів, зіставити їх та встановити відповідність між ними.

6. Перевірити роботу автоматичного визначення ключа на фрагментах тексту обсягом 100, 300 і 800 літер. Зафіксувати, за якого обсягу метод починає давати правильний результат стабільно.

7. Оформити звіт: тему й мету роботи, постановку задачі за варіантом, структурну схему програми, лістинг програми з коментарями, знімки екрана з результатами тестування, таблиці частот відкритого й шифрованого текстів.

8. Зробити висновок, у якому пояснити, чому збільшення розміру ключового простору шифру простої заміни не підвищує його стійкості до частотного аналізу.

## Вимоги до звіту

Звіт оформлюється на бланку встановленого зразка і має містити:

- тему, мету та обладнання;
- постановку задачі за індивідуальним варіантом;
- короткі теоретичні відомості про шифр Цезаря та частотний аналіз;
- текст програми з поясненням ключових функцій;
- результати роботи програми: шифрування, дешифрування, визначення ключа;
- знімки екрана із сеансом роботи;
- висновок за результатами роботи.

## Контрольні запитання

Запитання згруповано за рівнями навчальних досягнень. Для позитивної оцінки студент має відповісти на запитання середнього рівня, оцінка «добре» потребує відповідей достатнього рівня, оцінка «відмінно» — високого.

### Середній рівень (репродуктивний)

1. Що таке відкритий текст, шифротекст і ключ?
2. Як пов'язані між собою криптографія та криптоаналіз?
3. Сформулюйте правило Керкгоффса.
4. Чим шифри заміни відрізняються від шифрів перестановки? Наведіть приклад кожного типу.
5. Запишіть формули зашифрування й розшифрування для шифру Цезаря.
6. Скільки різних ключів має шифр Цезаря для української абетки?
7. Що таке відносна частота символу в тексті?
8. Який мінімальний обсяг тексту потрібен для надійного частотного аналізу?

### Достатній рівень (конструктивно-варіативний)

1. Чому таємність алгоритму не вважається надійною основою стійкості шифру?
2. Чому у формулі розшифрування шифру Цезаря додається N?
3. Скільки ключів має шифр довільної простої заміни і чому цей величезний простір не робить його стійким?
4. Як саме змінюється гістограма частот після зашифрування шифром Цезаря?
5. Опишіть алгоритм визначення ключа за критерієм χ². Які величини в ньому порівнюються?
6. Чому частотний аналіз не спрацьовує на коротких текстах?
7. Запишіть, як обчислити очікувану кількість входжень літери для тексту довжиною n.
8. Як перевірити правильність знайденого ключа програмно, без участі людини?

### Високий рівень (творчий)

1. У яких випадках частотний аналіз шифру Цезаря дає хибний результат? Запропонуйте спосіб підвищити надійність визначення ключа.
2. Поясніть, чому моноалфавітні шифри принципово не здатні приховати статистику мови, і які властивості має мати шифр, щоб її приховати.
3. Оцініть, скільки часу знадобиться на повний перебір ключів шифру простої заміни, і поясніть, чому це не робить шифр стійким.
4. Сформулюйте критерій, за яким сучасний шифр вважають стійким, і покажіть, яким саме вимогам шифр Цезаря не відповідає.
