## Linux — основа сучасної інфраструктури

Linux працює скрізь:
- **близько 90%** сайтів, чию ОС удається визначити, працюють на Unix-подібних системах; сам Linux — приблизно 60% (W3Techs, 2026)
- **близько 70%** мобільних пристроїв — Android, тобто ядро Linux (StatCounter, 2026)
- **100%** суперкомп'ютерів зі списку TOP500 (червень 2026)
- **Tesla**, SpaceX Dragon, марсіанський гелікоптер NASA Ingenuity
- Ваш роутер, Smart TV, холодильник

При цьому на десктопах лише ~4%. Чому така різниця? Розберемося.

```bash
# Версія ядра
```

Звідки взагалі два набори каталогів — `/bin` і `/usr/bin`? Історія UNIX: на початку 1970-х система на PDP-11 перестала вміщатися на перший диск, і частину програм перенесли на другий, змонтований у `/usr` (спершу там жили домашні каталоги користувачів — звідси й назва). У `/bin` лишилося лише те, що потрібне для завантаження до монтування другого диска. Причина давно зникла, а розділення жило десятиліттями. Сучасні дистрибутиви повернули все в `/usr`, лишивши `/bin` і `/lib` символьними посиланнями для сумісності.

Каталог `/run` — молодший: він живе в оперативній пам'яті (tmpfs) і очищується під час кожного завантаження. Там служби тримають те, що має сенс лише поки система працює: номери своїх процесів, сокети для зв'язку, блокування.

```bash

whoami
id

# Змінити права
chmod 755 script.sh
chmod +x script.sh      # Додати executable

# Змінити власника
sudo chown user:group file.txt

# Список користувачів
cat /etc/passwd

# Групи користувача
```

## Чому Linux?

| Перевага | Пояснення |
|----------|-----------|
| **Безкоштовний** | Немає ліцензійних витрат |
| **Open Source** | Можна модифікувати, аудитувати код |
| **Стабільний** | Сервери місяцями працюють без збоїв; ядро можна латати навіть без перезавантаження (livepatch) |
| **Безпечний** | Швидкі патчі, менше malware |
| **Гнучкий** | Від IoT до суперкомп'ютерів |
| **Ефективний** | Менше ресурсів для тієї ж роботи |
| **Спільнота** | Величезна база знань, підтримка |

```bash
# 6. Встановлені пакети (Debian/Ubuntu)
dpkg -l | wc -l
apt list --installed | head -20
```

## 🎯 Міні-проект (30 хв)

### Завдання: Створіть власний скрипт System Information Dashboard

Створіть Bash-скрипт, який красиво виводить всю інформацію про вашу Linux-систему. Це ваш перший "справжній" Linux-інструмент!

**Кроки:**

1. Створіть файл скрипта:
```bash
mkdir -p ~/scripts
nano ~/scripts/sysinfo.sh
```

2. Напишіть скрипт з наступним вмістом:
```bash
#!/bin/bash
# System Information Dashboard
# Автор: [Ваше ім'я]

# LC_ALL=C — щоб вивід lscpu і free був англійською за будь-якої мови
# системи: на українській локалі lscpu пише «Назва моделі», і grep
# за 'Model name' нічого б не знайшов
export LC_ALL=C

clear
echo "╔══════════════════════════════════════════════════════════════╗"
echo "║              SYSTEM INFORMATION DASHBOARD                    ║"
echo "╚══════════════════════════════════════════════════════════════╝"
echo ""
echo "[ СИСТЕМА ]"
echo "   Hostname:     $(hostname)"
echo "   Дистрибутив:  $(grep PRETTY_NAME /etc/os-release | cut -d'"' -f2)"
echo "   Ядро:         $(uname -r)"
echo "   Uptime:       $(uptime -p)"
echo ""
echo "[ HARDWARE ]"
echo "   CPU:          $(lscpu | grep 'Model name' | cut -d':' -f2 | xargs)"
echo "   RAM:          $(free -h | awk '/Mem:/ {print $3 " / " $2}')"
echo "   Диск (/):     $(df -h / | awk 'NR==2 {print $3 " / " $2 " (" $5 ")"}')"
echo ""
echo "[ ПРОЦЕСИ ]"
echo "   Всього:       $(ps aux | wc -l)"
echo "   Init:         $(ps -p 1 -o comm=)"
echo "   Top 3 CPU:    $(ps aux --sort=-%cpu | awk 'NR<=4 && NR>1 {print $11}' | tr '\n' ' ')"
echo ""
echo "[ МЕРЕЖА ]"
echo "   IP:           $(hostname -I | awk '{print $1}')"
echo "   Gateway:      $(ip route | grep default | awk '{print $3}')"
echo ""
echo "Звіт від $(date '+%Y-%m-%d %H:%M:%S')"
```

3. Зробіть скрипт виконуваним та запустіть:
```bash
chmod +x ~/scripts/sysinfo.sh
~/scripts/sysinfo.sh
```

4. Додайте alias для швидкого запуску:
```bash
echo 'alias sysinfo="~/scripts/sysinfo.sh"' >> ~/.bashrc
source ~/.bashrc
sysinfo
```

**Очікуваний результат:**
- Готовий скрипт `~/scripts/sysinfo.sh`
- Alias `sysinfo` для швидкого виклику
- Красивий вивід інформації про систему у форматі dashboard

**Бонус (для допитливих):**
- Додайте кольоровий вивід (використовуйте `\e[32m` для зеленого, `\e[0m` для скидання)
- Додайте інформацію про завантажені модулі ядра (`lsmod | wc -l`)
- Зробіть так, щоб скрипт автоматично запускався при кожному відкритті терміналу. Обережно: `~/.bashrc` виконується й для неінтерактивних оболонок — `scp` чи `rsync` через SSH ламаються, якщо він щось друкує. Тому виклик огортають перевіркою: `[[ $- == *i* ]] && ~/scripts/sysinfo.sh`
- Збережіть вивід у файл: `sysinfo > ~/system-report-$(date +%Y%m%d).txt`

## Тест для самоперевірки

Десять запитань, у кожному одна правильна відповідь. Якщо тема винесена вашій групі на самостійне опрацювання, цей самий тест публікується в Google Classroom — 10 балів, по одному за кожне запитання.

**1.** Що саме створив Лінус Торвальдс 1991 року?

- набір утиліт GNU
- систему ініціалізації
- ядро операційної системи
- повноцінний дистрибутив із графічною оболонкою

**2.** Чому систему коректно називати GNU/Linux?

- ядро дає Linux, а базові утиліти й компілятор — проєкт GNU
- GNU розробив ядро, а Linux — утиліти
- так називають лише комерційні дистрибутиви
- GNU — це назва графічної оболонки

**3.** Що таке systemd?

- пакетний менеджер
- графічне середовище
- файлова система
- система ініціалізації та керування службами

**4.** Яка команда покаже стан служби?

- service list
- systemctl status назва
- journalctl -u назва
- ps aux

**5.** Які права дає `chmod 755`?

- rw-r--r--
- r-xr-xr-x
- rwxrwxrwx
- rwxr-xr-x

**6.** Яке числове представлення має набір прав `rw-r--r--`?

- 755
- 644
- 600
- 664

**7.** Що містить віртуальна файлова система `/proc`?

- журнали служб
- відомості про процеси та стан ядра, згенеровані на льоту
- тимчасові файли програм
- резервні копії конфігурацій

**8.** У якому каталозі за стандартом FHS лежать конфігураційні файли системи?

- /etc
- /var
- /usr
- /opt

**9.** Яка команда оновить список доступних пакетів у Debian чи Ubuntu?

- apt upgrade
- apt install
- dpkg -l
- apt update

**10.** Чому Linux посідає всі 500 позицій у списку TOP500 суперкомп'ютерів?

- відкритий код дає змогу налаштувати ядро під конкретне обладнання, а ліцензія нічого не коштує
- виробники обладнання не випускають драйверів під інші системи
- він єдиний підтримує багатоядерні процесори
- інші системи не мають мережевого стека

## Підсумок

| Компонент | Опис |
|-----------|------|
| **Kernel** | Ядро Linux — керує hardware |
| **GNU tools** | Базові утиліти (bash, coreutils) |
| **systemd** | Система ініціалізації |
| **Package Manager** | apt, dnf, pacman |
| **Filesystem** | ext4, XFS, Btrfs |

**Ключові файли:**
- `/etc/passwd` — користувачі
- `/etc/fstab` — монтування
- `/var/log/` — логи
- `/proc/`, `/sys/` — інформація про систему

На наступній лекції розглянемо різні дистрибутиви Linux та як обрати потрібний.
