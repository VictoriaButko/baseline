## Три джерела — три різні відповіді

Запитайте, яку частку ринку має Linux на настільних комп'ютерах, і отримаєте
відповіді, що різняться в десятки разів залежно від джерела:

```
┌─────────────────────────────────────────────────────────────────────┐
│                      ОДНЕ ПИТАННЯ, РІЗНІ ЦИФРИ                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   Лічильник відвідувань сайтів    одиниці відсотків                 │
│   Опитування розробників          десятки відсотків                 │
│   Опитування гравців              одиниці відсотків                 │
│   Продажі нових комп'ютерів       частки відсотка                   │
│   Сервери в дата-центрах          більшість                         │
│   Суперкомп'ютери зі списку TOP500 усі 500                          │
│   Смартфони (ядро Linux всередині) більшість пристроїв світу        │
│                                                                     │
│   Жодна з цифр не є помилковою. Вони просто відповідають            │
│   на РІЗНІ питання, хоч і звучать однаково.                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

Ця тема — не про те, «хто популярніший». Вона про те, як читати статистику,
щоб не стати жертвою власного висновку.

**Запитання до аудиторії**: якщо сайт бачить, що 4 % відвідувачів мають Linux,
що саме виміряно — частка користувачів, частка пристроїв чи частка переглядів
сторінок?

## Чотири способи виміряти поширеність

```
┌─────────────────────────────────────────────────────────────────────┐
│                 МЕТОДИ ТА ЇХНІ ОДИНИЦІ ВИМІРЮВАННЯ                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   1. ЛІЧИЛЬНИКИ ВІДВІДУВАНЬ                                         │
│      Одиниця: перегляд сторінки. Джерело: рядок User-Agent          │
│      Зсув: активні користувачі важать більше; сервери,              │
│      кіоски й пристрої без браузера не враховані взагалі.           │
│                                                                     │
│   2. ДАНІ ПРО ПОСТАЧАННЯ                                            │
│      Одиниця: проданий пристрій. Джерело: аналітичні агенції        │
│      Зсув: не видно, що встановили після купівлі; не видно          │
│      старих машин, які досі працюють.                               │
│                                                                     │
│   3. ОПИТУВАННЯ                                                     │
│      Одиниця: відповідь людини. Джерело: анкети спільнот            │
│      Зсув: відповідає той, хто захотів; аудиторія                   │
│      конкретного сайту не є зрізом населення.                       │
│                                                                     │
│   4. ТЕЛЕМЕТРІЯ ТА ЛІЧИЛЬНИКИ ПАКЕТІВ                               │
│      Одиниця: встановлення. Джерело: сама система                   │
│      Зсув: участь добровільна, вмикають не всі.                     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**Ключова думка**: перш ніж порівнювати два числа, треба переконатися, що в них
однакова **одиниця вимірювання**. Перегляди сторінок, продані пристрої й
відповіді в анкеті — три різні речі, і жодна з них не дорівнює «кількості
користувачів».

## Чому цифри розходяться: п'ять причин

| Причина | Як проявляється |
|---------|-----------------|
| Різна одиниця | перегляди / пристрої / люди / встановлення |
| Різна аудиторія | відвідувачі новинних сайтів проти відвідувачів форуму розробників |
| Підроблюваність джерела | рядок User-Agent змінюється однією настройкою браузера |
| Боти й трафік без людей | частину переглядів роблять програми, а не люди |
| Сегмент ринку | настільні, серверні, мобільні, вбудовані — різні світи |

### Приклад того, як одна деталь змінює висновок

Браузер повідомляє про себе рядком, який можна змінити. Подивіться власний:

```bash
# Що ваш браузер каже про систему (виконайте у консолі браузера)
# navigator.userAgent

# Те саме з командного рядка
curl -s -A "$(uname -sr)" https://example.com > /dev/null &&   echo "запит надіслано з рядком: $(uname -sr)"
```

Якщо частина користувачів однієї системи налаштовує браузер так, щоб
представлятися іншою системою (задля сумісності чи приватності), лічильник
занизить їхню частку. Для дрібних часток така похибка може бути порівнянною з
самою величиною.

### Як один пристрій зсуває статистику

Щомісячне опитування Steam показує частку Linux серед гравців. Роками вона
трималася близько одного відсотка, а 2025 року вперше перевищила три — і
значну частину приросту дав не перехід людей на Linux, а портативна консоль
Steam Deck зі SteamOS, яка в опитуванні рахується як Linux. Питання «чи стали
гравці частіше обирати Linux» і «скільки пристроїв Steam працюють на ядрі
Linux» мають різні відповіді, хоча спираються на ту саму цифру.

### Розбір помилкових міркувань

> «Лічильник показує в Linux одиниці відсотків — отже, ця система нікому не
> потрібна.»

Помилка узагальнення з одного сегмента на всі. Той самий код ядра працює в
більшості серверів світу, в усіх машинах списку TOP500 і в мільярдах
смартфонів. Правильне формулювання звучить інакше: «частка настільних
комп'ютерів із Linux, виміряна за переглядами сторінок, становить одиниці
відсотків».

> «Опитування розробників показало десятки відсотків — отже, Linux поширеніший,
> ніж кажуть лічильники.»

Помилка вибірки. Відповідали ті, хто читає конкретний сайт для програмістів і
захотів заповнити анкету. Це чудові дані про **цю спільноту** й погані дані про
населення взагалі. Обидва числа правильні у своїх межах; неправильне лише
поширення їх за ці межі.

> «Цифри з різних джерел суперечать одна одній — значить, статистиці вірити не
> можна.»

Найшкідливіший висновок. Джерела не суперечать — вони відповідають на різні
питання. Уміння читати статистику полягає не у виборі «правильного» джерела, а
в умінні щоразу запитувати: що саме вимірювали, на якій вибірці, якою одиницею
й хто платив за дослідження.

про мови програмування, бази даних, фреймворки й будь-які галузеві рейтинги.

## Що впливає на поширеність насправді

Технічна якість — лише один із чинників, і не найважливіший.

| Чинник | Приклад дії |
|--------|-------------|
| Попереднє встановлення | система, що стоїть на новому ноутбуці, має величезну перевагу |
| Сумісність із наявними файлами | організація не перейде, якщо контрагенти надсилають несумісні документи |
| Наявність потрібних програм | одна незамінна програма визначає вибір усієї системи |
| Вартість переходу | перенавчання персоналу дорожче за ліцензії |
| Звичка та навчання | людина обирає те, з чим працювала в школі |
| Екосистема пристроїв | телефон, годинник і комп'ютер однієї компанії працюють разом |

**Мережевий ефект** пояснює стійкість позицій краще за будь-які технічні
порівняння: цінність системи для користувача зростає з кількістю інших
користувачів, бо з'являються програми, документи, навчальні матеріали й фахівці.
Тому зміна часток відбувається повільно, а різкі зсуви трапляються лише там, де
з'являється **новий сегмент**: так Android зайняв ринок, якого раніше не
існувало, а не відібрав частку в настільних систем.

## Практичне завдання

1. Знайдіть три різні джерела даних про поширеність ОС і для кожного випишіть:
   одиницю вимірювання, аудиторію, спосіб збору.
2. Поясніть, чому дані про продажі нових пристроїв і дані лічильників не можуть
   збігатися навіть теоретично.
3. Наведіть приклад питання про ОС, на яке **не можна** відповісти лічильником
   відвідувань.
4. Сформулюйте коректно, з указанням сегмента й одиниці, три твердження про
   поширеність систем.

## Тест для самоперевірки

Десять запитань, у кожному одна правильна відповідь. Якщо тема винесена вашій групі на самостійне опрацювання, цей самий тест публікується в Google Classroom — 10 балів, по одному за кожне запитання.

**1.** Що є одиницею вимірювання для лічильників відвідувань сайтів?

- проданий пристрій
- встановлена копія системи
- окремий користувач
- перегляд сторінки

**2.** Чому дані про продажі нових пристроїв не показують реальної картини використання?

- продажі не фіксуються документально
- вони збираються лише в одній країні
- вони враховують лише серверне обладнання
- не видно, що встановили після купівлі, і не враховані старі машини

**3.** У чому головний зсув опитувань спільнот розробників?

- у них беруть участь лише великі компанії
- відповідають ті, хто читає конкретний сайт і захотів заповнити анкету
- вони проводяться надто рідко
- відповіді збираються автоматично без відома людей

**4.** Чому рядок User-Agent є ненадійним джерелом?

- його можна змінити налаштуванням браузера
- він не передається серверу
- його бачить лише сам користувач
- він однаковий для всіх систем

**5.** Яку систему використовують усі машини зі списку TOP500?

- Windows Server
- FreeBSD
- Linux
- macOS

**6.** Чому питання «яка ОС найпопулярніша» без указання сегмента некоректне?

- у різних сегментах перемагають різні системи
- популярність неможливо виміряти в принципі
- усі джерела даних недостовірні
- частки змінюються щодня

**7.** Який висновок із розбіжності джерел правильний?

- правильним є те джерело, у якого більша вибірка
- статистиці взагалі не можна довіряти
- джерела відповідають на різні питання, і порівнювати треба однакові одиниці
- усі джерела навмисно спотворюють дані

**8.** Що з переліченого найбільше впливає на поширеність системи?

- попереднє встановлення на нових пристроях і сумісність із наявними файлами
- технічна досконалість ядра
- рік випуску першої версії
- кількість рядків коду

**9.** Що таке мережевий ефект у контексті ОС?

- швидкість роботи залежить від якості мережі
- система оновлюється лише за наявності інтернету
- цінність системи зростає зі збільшенням кількості її користувачів
- популярність вимірюється мережевим трафіком

**10.** Чому Android зайняв ринок швидко, а настільні частки змінюються повільно?

- він технічно досконаліший за інші системи
- він з'явився в новому сегменті, а не відбирав частку в наявному
- настільні системи перестали розвиватися
- його роздавали безкоштовно користувачам

## 🎯 Міні-проект (30 хв)

### Завдання: власне дослідження з описаною методикою

Мета — провести маленьке дослідження та описати його так, щоб інший студент міг
його повторити й отримати те саме.

**Кроки:**

1. Оберіть доступну вам вибірку: студенти вашої групи, відвідувачі шкільного
   сайту, комп'ютери в аудиторії — будь-що, до чого маєте доступ.

2. Сформулюйте питання так, щоб у ньому були **сегмент і одиниця**. Наприклад:
   «Яку частку **настільних комп'ютерів аудиторії 214** займає кожна ОС?»

3. Зберіть дані. Для комп'ютерів аудиторії:

```bash
cat /etc/os-release | grep PRETTY_NAME
uname -sr
```

4. Опишіть методику за п'ятьма питаннями чек-листа: що, де, як, хто, чи
   відтворюється.

5. Окремо випишіть **межі застосовності**: про що ваші дані не говорять нічого.

**Очікуваний результат:** таблиця з результатами плюс абзац про межі, у якому
чесно сказано, що вибірка не є зрізом населення.

**Бонус (для допитливих):**

- Порівняйте свій результат із даними будь-якого публічного джерела й поясніть
  розбіжність через різницю вибірок, а не через «помилку» одного з джерел.

**Ключовий висновок:** у цій темі важлива не жодна конкретна цифра — цифри
змінюються щороку. Важлива звичка щоразу запитувати, що саме виміряно і на кому.
Фахівець, який уміє поставити ці питання, правильно прочитає будь-яке
дослідження; той, хто їх не ставить, помилиться навіть із коректними даними.

На наступній лекції — спеціальні пристрої та термінали: обладнання, яке не
схоже на звичайний комп'ютер.
